# Django өнімділігі — лабораторная №11

Выполнен только этап 1: исходная, намеренно неоптимизированная страница.
Python 3.14, Django 5.2 LTS, SQLite, HTML и CSS.

## Запуск в Windows PowerShell / VS Code

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed
python manage.py check
python manage.py runserver
```

Если активация запрещена политикой PowerShell, запускайте команды напрямую:
`.\.venv\Scripts\python.exe manage.py runserver`.
В VS Code выберите интерпретатор `.venv\Scripts\python.exe`.

Сайт: http://127.0.0.1:8000/posts/ (корень перенаправляет на эту страницу).
Настройки предназначены для локальной лабораторной работы.

## Данные и исходная производительность

`seed` использует `random.seed(42)`, транзакцию и `bulk_create` пакетами
до 500 объектов. Создаются 200 авторов, 50 тегов, 20 000 публикаций,
60 000 связей с тегами (3 разных тега на публикацию) и 60 000 комментариев
(3 на публикацию). Повторный запуск на заполненных таблицах завершается
понятной ошибкой без изменения данных. База и окружение исключены из Git.
Случайный выбор воспроизводим; `created_at` содержит фактическое время создания.

`/posts/` выбирает последние 50 опубликованных записей. Шаблон отдельно
обращается к автору, тегам и числу комментариев каждой записи: ожидается
151 SQL-запрос. Оптимизация, кэширование и дополнительные индексы
на `status`/`created_at` пока не применяются. Стандартные индексы Django
для внешних ключей и M2M остаются.

## Проверка первого этапа

```powershell
python verify_stage1.py
```

Скрипт проверяет количества объектов и связей, последние 50 опубликованных
записей, казахский HTML, 151 SQL-запрос и отсутствие дополнительных индексов.
При исходном заполнении опубликовано 10 076 записей.
