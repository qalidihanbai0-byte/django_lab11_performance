# 12-зертханалық жұмыс бойынша қателерді талдау

Модель — Ollama 0.40.16 жүйесіндегі `qwen2.5-coder:1.5b`. 2026 жылғы 19 қарашада әр сұрақ екі промптпен бір рет орындалды.

| № | Baseline | Improved |
|---|---|---|
| Q01 | Клиент кестесінің орнына тапсырыс кестесін қолданды, Қарағанды бойынша сүзгі жоқ. | Қала атауын `Karaғанды` деп аралас әліпбимен жазды. |
| Q02 | Ең үлкен бағаның орнына тапсырыс берген клиенттерді санады. | `MAX(price)` орнына `COUNT(*)` қолданды, санат бойынша артық сүзгі қосты. |
| Q03 | Жаңа тапсырыстардың орнына бағасы оң тапсырыс жолдарын санады. | Кесте мен статус қате. `shop_orderitem.status` жоқ, қорғау сұранысты тоқтатты. |
| Q04 | Қала бағаны, клиентпен JOIN және қала бойынша GROUP BY жоқ. | Қала бойынша топтамады, тек төленген тапсырыстарды санады. |
| Q05 | Санат бойынша бірліктерді қоспады. `o.quantity` және `o.price` жоқ, `Delivered` статусы қате. Қорғау тоқтатты. | Ішкі SELECT қолдау тізіміне кірмейді. Ойдан санат қосты, санат бойынша топтау мен paid сүзгісі жоқ. |
| Q06 | Санаттарды шығарды, бірақ әр санаттағы тауар санын есептемеді. | Нәтиже сәйкес. Дегенмен каталогтағы барлық тауарды санады, тапсырыста кездесетін тауарлармен шектемеді. |
| Q07 | Қала бойынша топтау мен cancelled статусын алып тастайтын сүзгі жоқ. | Статус сүзгісі дұрыс, бірақ JOIN мен қала бойынша GROUP BY жоқ. |
| Q08 | Қыркүйектің орнына бүкіл жылды алды. Түсімнің орнына тапсырыстарды санады, paid сүзгісі жоқ. | paid сүзгісі дұрыс, бірақ қыркүйектің орнына бүкіл жыл алынды және түсімнің орнына тапсырыс саны есептелді. |
| Q09 | Орташа чек орнына жолдарды санады. `completed` статусы базада жоқ. | Тапсырыс кестесінде `price` бағаны жоқ, қорғау тоқтатты. Тауар бағасының орташа мәні орташа чекке тең емес. |
| Q10 | Ай бойынша санаудың орнына бір жолды сұрады. `shop_orderitem.name` жоқ, қорғау тоқтатты. | Ай бойынша санаудың орнына түсімді есептеуге тырысты. `shop_orderitem.status` жоқ, қорғау тоқтатты. |

Execution accuracy бойынша baseline 0/10 (0%), improved 1/10 (10%). Айырма +10 пайыздық тармақ. Q06-дағы нәтиже тек осы деректер жиынында сәйкес: барлық тауар тапсырыстарда кездеседі. Бір ұпай improved нұсқасының сұрақ мағынасын толық түсінгенін дәлелдемейді. Қауіпсіз SELECT те қате сан қайтара алады.
